# Animation

```javascript
stock.animation.play(animFile, controlGroup, playMode, reverse, initialValue);
```

| playMode | Meaning |
|----------|---------|
| `VALUE` | Direct scrub |
| `PLAY_FORWARD` / `PLAY_REVERSE` | One direction |
| `PLAY_BOTH` | Open + close (doors) |
| `LOOP` / `LOOP_SPEED` | Looping |

`stock.animation.get(name)`, `stock.animation.list()`.
