# Global objects

Auto-injected — no `import`.

## stock

All rolling-stock APIs: `control`, `coupler`, `readout`, `sound`, `animation`, `particle`, `cg_group`.

## math

Vectors, Bézier curves — [Math-EN](Math-EN).

## model

OBJ load, mesh transforms, rendering — [Model-EN](Model-EN).

## track

Track geometry; in **track scripts** `track.here()` / `track.pos()` use placement coords. See [Track-EN](Track-EN).

## print(message)

`[Script|<uuid8>|<path>] message` in log.

## time / util / random

[Stdlib-EN](Stdlib-EN).

> **Note**
> Rhino / ES5 recommended. No `require`, no `console.log`.
