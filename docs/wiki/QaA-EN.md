# Q&A

## IR Scripts vs IR JSON?

IR JSON = static definitions. IR Scripts = dynamic runtime logic.

## Need Java?

No — JavaScript with bundled Rhino. Use ES5 (`var`, `function`).

## Client or server?

**Server only.** Client handles UI, sounds, particles.

## One engine per train?

**Per stock entity instance** — each car has its own engine if scripted.
