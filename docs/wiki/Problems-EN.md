# FAQ

## LOOP stops after error

Uncaught exception permanently disables that LOOP function. Fix script, place new stock.

## getSpeed() missing

Use `stock.getSpeedKmh()` or `stock.readout.getSpeed()`.

## ES6 syntax?

Use ES5: `var` + `function`.

## Client scripts?

No — server only.

## Particles invisible?

Enable IR particles; try `[0, 4, 0]` coordinates.

See [Golden Field IR handbook](https://goldenfield192.github.io/) for resource packs.
