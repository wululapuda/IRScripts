# Debugging

Log: `versions/<name>/logs/latest.log`

| Prefix | Meaning |
|--------|---------|
| `[Bootstrap]` | Scan stock JSON |
| `[Registry]` | Register functions |
| `[Script\|...\|...]` | print / errors |
| `[TrackBootstrap]` | Scan track scripts |

JVM: `-Dirscripts.debug=true`, `-Dirscripts.scriptPrint=false`
