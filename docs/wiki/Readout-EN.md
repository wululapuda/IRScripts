# Readout

`stock.readout` — read-only gauge values matching IR GUI.

| Method | Description |
|--------|-------------|
| `getSpeed()` | 0~1 ratio |
| `getBoilerPressure()` | Steam boiler / maxPSI |
| `getEngineRpm()` | Diesel RPM |
| `getBrakePressure()` | Train brake pressure |
| `getCoupledFront()` / `getCoupledRear()` | Coupled 0/1 |
| `getHorn()` / `getBell()` | 0/1 |
