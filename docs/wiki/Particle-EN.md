# Smoke & steam

Model-space coordinates, server call, client render.

```javascript
stock.particle.smoke(start, offset, speed, time, concentration[, texture]);
stock.particle.steam(start, offset, speed, time[, texture]);
```

Emit point = `start + offset`. Enable IR particles in graphics settings.
