# Standard library

## time

`time.time()`, `time.monotonic()`, `time.sleep(seconds)` (non-blocking), `time.world_tick()`, `time.stock_tick()`, `time.TICKS_PER_SECOND` (= 20).

## util

`clamp`, `lerp`, `inverseLerp`, `mapRange`, `sign`, `approximately`, `mod`, `degToRad`, `radToDeg`.

## random

`random()`, `uniform`, `randint`, `choice`, `shuffle`, `seed`.
